# Workspace Rules & Preferences

## Dashboard UI Guidelines
- Do NOT mention specific underlying technologies, framework names, or algorithm buzzwords (e.g. `BATMAN-adv`, `gRPC`, `CBS MAPF`, `D* Lite`, `NH-ORCA`, `HMAC-SHA256`) in user-facing dashboard UI text or headers.
- Use clean, professional operational business terminology instead (e.g., `Peer Mesh Network`, `Path Planning`, `Collision Avoidance`, `Real-time Telemetry`, `Packet Integrity`).
- Ensure all text strictly uses Times New Roman font (`"Times New Roman", Times, serif !important`).
